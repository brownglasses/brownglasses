## What I care about

- **제품 맥락** — 사람의 실제 행동에서 시작해, 작고 분명한 제품 루프를 만듭니다.
- **끝까지 작동하는 경험** — 화면뿐 아니라 데이터, 권한, 실패 상황, 배포 준비를 함께 설계합니다.
- **검증 가능한 결과** — 자동화 결과와 실제 기기·화면 확인을 구분하고, 확인한 범위 안에서 말합니다.
