# 이혁진

제품의 문제를 정의하고, 실제로 쓸 수 있는 앱과 서비스를 만듭니다.

주로 **SwiftUI / iOS**, **TypeScript / 웹**, 그리고 사람의 검토가 남는 **AI 워크플로우**를 다룹니다. 아이디어와 화면에서 끝내지 않고, 데이터·권한·검증·출시 준비까지 연결하는 것을 좋아합니다.

## How I build

- 사람의 행동과 맥락에서 시작해, 작고 검증 가능한 제품 루프를 만듭니다.
- 개인정보, 권한, 비용, 자동화 실패를 기능의 나중 문제가 아니라 설계 조건으로 다룹니다.
- 자동 테스트와 실제 기기·화면 검증을 구분하고, 확인한 범위만 결과로 말합니다.
